Stateful models¶

Demonstrates. A reaction module with its own memory (a continuous-time LSTM whose hidden and cell state are integrated as extra ODE dimensions) and the opt-in that guards it.

Every module so far predicts rates from the current state alone. That is a real modeling assumption: it says the biology has no memory beyond what is currently measured. A stateful module relaxes that: it carries its own latent state through the solve, so the rates can depend on where the process has been, not just where it is.

Why this is a bigger change than it looks¶

hybrax.train does not run a discrete recurrent network beside the ODE solver. It turns the recurrent cell into a continuous-time ODE: the latent state h is an extra integrated dimension, and its derivative is the discrepancy between h and whatever the cell would have jumped to next: d(h)/dt = cell(input, h) - h. As training pulls the residual to zero, h tracks the same trajectory the discrete cell would have taken, but now it is a proper flow that Diffrax can integrate and differentiate through like any other state.

This is exactly how hybrax.train’s own built-in stateful model works: DefaultStatefulReactionModule in hybrax/train/defaults.py uses this trick with a GRU cell. What follows applies the identical trick to an LSTM, to show it is a general pattern, not something specific to GRUs.

The walkthrough below shows the file in pieces, next to the reasoning for each one. For the whole thing at once: to copy, diff against your own, or just read top to bottom:

Full custom.py
  1"""A stateful reaction module: a continuous-time LSTM.
  2
  3Every reaction module so far has been memoryless: its rates depend only on
  4the CURRENT state. A stateful module (``n_latent > 0``) adds its own hidden
  5state, integrated as extra ODE dimensions alongside the physical ones, so the
  6rates can depend on the process's recent history too.
  7
  8hybrax.train's own default stateful module uses a GRU cell (see
  9``DefaultStatefulReactionModule`` in ``hybrax/train/defaults.py``); this one uses
 10an LSTM cell instead, to show the same trick applies to any recurrent cell
 11with a fixed-size hidden state.
 12"""

 28class LSTMReactionModule(UserReactionModule):
 29    """Cell state and hidden state are both integrated ODE latents, each
 30    pulled toward the LSTM cell's discrete target at every solver step."""
 31
 32    lstm_cell: eqx.nn.LSTMCell = trainable_field()
 33    rate_head: eqx.nn.Linear = trainable_field()
 34    n_hidden: int = eqx.field(static=True)
 35
 36    def __init__(self, *, key, n_hidden=4, **scale_kwargs):
 37        # SCL_latent holds [hidden | cell], so its width is 2 * n_hidden.
 38        scale_kwargs = {**scale_kwargs, "SCALE_latent": jnp.ones(2 * n_hidden)}
 39        super().__init__(**scale_kwargs)
 40        self.n_hidden = n_hidden
 41        key_cell, key_head = jax.random.split(key)
 42        self.lstm_cell = eqx.nn.LSTMCell(
 43            input_size=self.n_modeled_RMCs, hidden_size=n_hidden, key=key_cell
 44        )
 45        self.rate_head = eqx.nn.Linear(
 46            in_features=n_hidden + self.n_modeled_RMCs,
 47            out_features=self.n_modeled_BiologicalOde_rates,
 48            key=key_head,
 49        )
 50
 51    def __call__(self, t, inputs: ReactionInputs) -> ReactionOutputs:
 52        del t
 53        h, c = jnp.split(inputs.SCL_latent, 2)
 54        h_new, c_new = self.lstm_cell(inputs.SCL_modeled_RMCs, (h, c))
 55        # The continuous-time-RNN trick: an ODE derivative that pulls the
 56        # latent toward the cell's one-step target, rather than the discrete
 57        # jump an LSTM normally takes. At convergence h tracks h_new.
 58        latent_derivative = jnp.concatenate([h_new, c_new]) - inputs.SCL_latent
 59        # Read out from h (not h_new): the CURRENT hidden state, consistent
 60        # with every other input the reaction module receives at time t.
 61        readout = jnp.concatenate([h, inputs.SCL_modeled_RMCs])
 62        return ReactionOutputs(
 63            SCL_modeled_BiologicalOde_rates=self.rate_head(readout),
 64            SCL_modeled_Outflows_rates=jnp.zeros(0),
 65            SCL_modeled_Inflows_rates=jnp.zeros(0),
 66            SCL_latent_derivative=latent_derivative,
 67        )

 75def estimate_all_scales(runtime_data, target_names, config):

 77    rhs = runtime_data.rhs_ode
 78    n_processes = len(runtime_data.process_order)
 79
 80    def max_abs_state(name):
 81        best = 0.0
 82        for i in range(n_processes):
 83            _, values = runtime_data.raw_state_trace(i, name)
 84            if values.size:
 85                best = max(best, float(np.max(np.abs(values))))
 86        return max(best, 1e-6)
 87
 88    rmc_scale = {name: max_abs_state(name) for name in rhs.name_modeled_RMCs}
 89
 90    def rate_scale_for(species):
 91        per_process = []
 92        for i in range(n_processes):
 93            c_times, c_values = runtime_data.raw_state_trace(i, species)
 94            x_times, x_values = runtime_data.raw_state_trace(i, "biomass")
 95            exposure = np.trapezoid(x_values, x_times)
 96            per_process.append(abs(c_values[-1] - c_values[0]) / max(exposure, 1e-9))
 97        return max(max(per_process), 1e-9)
 98
 99    rate_scale = [rate_scale_for(name[2:]) for name in rhs.name_modeled_rates]
100
101    # Note: no SCALE_latent here. LSTMReactionModule.__init__ sizes and sets
102    # it itself from n_hidden, since the latent has no physical counterpart
103    # in the data for this hook to estimate a magnitude from.
104    empty = jnp.zeros(0)
105    return EstimatedScales(
106        SCALE_modeled_RMCs=jnp.asarray([rmc_scale[n] for n in rhs.name_modeled_RMCs]),
107        SCALE_modeled_BiologicalOde_rates=jnp.asarray(rate_scale),
108        SCALE_V_in_cumulative=jnp.asarray(
109            max(runtime_data.initial_volume(i) for i in range(n_processes))
110        ),
111        SCALE_modeled_Inflows_cumulative=empty,
112        SCALE_modeled_Inflows_rates=empty,
113        SCALE_modeled_Outflows_cumulative=empty,
114        SCALE_modeled_Outflows_rates=empty,
115        SCALE_controlled_Inflows_cumulative=empty,
116        SCALE_controlled_Inflows_rates=empty,
117        SCALE_controlled_Outflows_cumulative=empty,
118        SCALE_controlled_Outflows_rates=empty,
119        SCALE_controlled_PVs=empty,
120        SCALE_controlled_Inflows_Cin=jnp.maximum(
121            jnp.abs(jnp.asarray(rhs.Cin_controlled_Inflows)), 1.0
122        ),
123        SCALE_modeled_Inflows_Cin=jnp.maximum(
124            jnp.abs(jnp.asarray(rhs.Cin_modeled_Inflows)), 1.0
125        ),
126    )

An LSTM cell has two pieces of memory, not one (the hidden state and the cell state) so SCL_latent here holds both, concatenated. Everything else is the same trick as above: compute where the cell would jump to, emit the difference as the derivative, and read the rates out of the current hidden state (not the target) so the module stays consistent with every other input it receives at time t.

ReactionOutputs gains a field we have not used before, SCL_latent_derivative, aligned with SCL_latent. It defaults to an empty array: every non-stateful module in these docs has been quietly relying on that default.

The opt-in¶

Declaring a nonzero SCALE_latent is enough to make n_latent > 0, and that alone is not allowed to train silently:

ValueError: Stateful reaction modules (n_latent > 0) require explicit opt-in: set train.allow_stateful_models=true.

That is deliberate: a latent state changes what the model is (it is no longer a pure function of the physical state) and that is a large enough change in what “the model” means that hybrax.train wants it to be a decision, not a side effect of adding a field.

{ "train": { "allow_stateful_models": true } }

When this is worth the extra machinery¶

Not on demo_batch: a memoryless module already fits this data well, because nothing about a simple batch culture actually depends on history beyond the current state. A latent state earns its cost when the biology genuinely has memory the current measurements don’t capture: induction that takes hours to take effect, a metabolic shift that depends on how long a culture has been glucose-limited, product formation that lags behind the growth that caused it. If a memoryless module systematically mis-fits in a way that correlates with elapsed time rather than with the current state, that is the signal to reach for this.

Gotchas¶

  • allow_stateful_models: true is required, or training raises before it starts.

  • Read out from the current latent, not the target: using h_new instead of h in the rate head quietly changes the model’s causal structure (the rate would depend on information from the next step).

  • SCL_latent_derivative has a default of empty. Forgetting to set it on a stateful module is a shape mismatch, not a silent zero.

  • This adds real parameters and real integration cost. Confirm a memoryless module actually underfits before reaching for this: see Tutorial 3 and 4 for the memoryless baseline.
