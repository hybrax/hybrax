class hybrax.train.runtime_context.ProducerCollectionData[source]¶

Unfiltered producer-side view of one whole prepared collection.

This is the broad intermediate the producer builds once. It is never handed to a hook: select_training_parents() narrows it to the fold’s represented parents first, and only that narrowed RuntimeDataContext is hook-visible.

class hybrax.train.runtime_context.RuntimeDataContext[source]¶

One fold’s training parents, as seen by the producer-side scale hook.

Every row is a unique non-augmented parent represented by fold.train, in canonical parent order, so there is no augmentation mapping to carry.

hybrax.train.runtime_context.rhs_ode_from_training_parents(collection, *, empty_message='requires a non-empty collection')[source]¶

Build the shared RhsOde of a parent collection, rejecting disagreement.

Every parent must declare an equivalent BiologicalOde, so the first one’s RhsOde speaks for all of them.

Parameters:

  • collection (hybrax.format.dataclasses.BioProcessCollection) – Parent process collection.

  • empty_message (str) – Raised verbatim when collection has no processes, so the diagnostic reads in the caller’s terms.

Returns:

The shared RhsOde.

Raises:

ValueError – If collection is empty, or its parents declare non-equivalent biological_ode blocks.
