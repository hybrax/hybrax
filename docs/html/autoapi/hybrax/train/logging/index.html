class hybrax.train.logging.RunLogger(*, log_process_losses=False, metrics_csv=None, metrics_jsonl=None, log_decimals=4, logger_name='hybrax.train.harness')[source]¶

Console table + in-memory history + metrics.csv/metrics.jsonl writer.

One instance covers one training run: start() opens the output files and prints the run banner, record_step() is called once per training step, and finalize()/close() flush and release the file handles. Usable as a context manager (__enter__/__exit__ call close()).

Parameters:

  • log_process_losses (bool)

  • metrics_csv (str | pathlib.Path | None)

  • metrics_jsonl (str | pathlib.Path | None)

start(*, target_names, process_names, total_updates, compile_warmup_seconds)[source]¶

Open the CSV/JSONL files (if configured) and log the run banner.

Parameters:

  • target_names (Sequence[str]) – Loss-term names, in the order every step’s per_target_loss is reported in.

  • process_names (Sequence[str]) – Every process in the training run, for the banner only.

  • total_updates (int) – Total optimizer steps the run will take, used to size the console table’s step column.

  • compile_warmup_seconds (float) – JIT warmup time to report in the banner.

Return type:

None
