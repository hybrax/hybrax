# Gallery: Feeds, boluses and samples

A continuous feed, two boluses and sampling events in one run, and a reaction
module that reads the feed rate and a controlled process variable (dissolved
oxygen) as real biological inputs.

Narrated version: `docs/source/gallery/fed_batch.md`.

## Run

```bash
python run.py
```

2000 epochs (this dataset is harder than the tutorials' pure batch). Output
lands in `run/`.
